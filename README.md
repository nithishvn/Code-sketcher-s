About This Project

Welcome to Code Sketchers! This repository is created to learn and demonstrate Git, GitHub, and developer collaboration.

Objectives

- Learn Git and GitHub basics.
- Understand commits and branches.
- Practise pull requests.
- Improve team collaboration.
- Maintain project documentation.

Technologies Used

- Git
- GitHub
- Markdown

Git Workflow

1. Create a branch.
2. Make changes.
3. Commit changes.
4. Push changes to GitHub.
5. Create a pull request.
6. Review and merge changes.

Team Collaboration

Team members can contribute by creating branches, making commits, and submitting pull requests.

Code Sketchers Team

Conclusion

This project demonstrates the basic GitHub workflow used by developers.
